## 1. 入口选型

| 你想… | 用 | 注意 |
|---|---|---|
| 建立基线、调试、单机求解 | `pso_serial` | 结果作为其他入口的正确性参照 |
| 同一群粒子分给多进程，要求结果与串行一致 | `pso_mpi_ms` | 保留作对照方案；加速来自评估分摊 |
| 多岛独立演化 + 周期迁移，追求可扩展的质量/加速 | `pso_mpi_island` | 本项目主推方案；结果随 rank 数变化（设计使然） |

深入原因见 [02-优化设计方案.md](02-优化设计方案.md)（维护者向）。

## 2. 常用参数与选择建议

最常用选项（完整定义、取值范围与全部选项见
[06-PSO命令行与结果接口参考.md](06-PSO命令行与结果接口参考.md)）：

| 选项 | 默认值 | 什么时候动它 |
|---|---|---|
| `--function NAME` | `rastrigin` | 换测试问题（见第 3 节） |
| `--particles N` | 20000 | 群体大小；越大越稳、每代越贵 |
| `--dim N` | 50 | 问题维度 |
| `--max-evals N` | 1000000 | 统一预算；做比较时固定它 |
| `--max-iters N` | 1000 | 仅 `--max-evals 0` 时生效 |
| `--seed N` | 20240229 | 复现；多次运行取统计时逐个换 |
| `--target X` | 1e-8 | 成功阈值；达到即早停 |
| `--boundary MODE` | `reflect` | 越界策略；`reflect` 适用于大多数场景，`clamp`/`reinit` 为消融对照/重探索选项（语义见 [05-PSO算法与优化理论.md](05-PSO算法与优化理论.md) §4） |
| `--lower X` / `--upper X` | 随函数 | 覆盖函数默认搜索边界 |
| `--linear-inertia` | 关 | 切换到 w=0.9→0.4 对照动力学 |
| `--no-early-stop` | 关 | 固定预算比较时打开 |
| `--pin-cpus` | 关 | 计时实验绑核（协议见 [03-基准测试报告.md](03-基准测试报告.md)） |
| `--history PATH` | 无 | 保存逐代收敛轨迹 |
| `--migration-interval N` | 10 | 岛模型迁移周期 |
| `--verbose` / `--quiet` | quiet | 打印/关闭进度行 |

参数选择三原则：

1. **固定预算比结果**：比较不同配置时固定 `--max-evals`，别比迭代数。
2. **多次运行才下统计结论**：单次运行可用于验证管线与格式，不能作为结论
   依据；结论需要 ≥30 个 seed 的统计（见 [03-基准测试报告.md](03-基准测试报告.md)，
   配对 Wilcoxon + bootstrap）。
3. **先别动 χ/c1/c2/vmax_ratio**：默认值是标准收缩因子设定；想改先读
   [05-PSO算法与优化理论.md](05-PSO算法与优化理论.md) 的稳定性依据。

放量前先冒烟：换新函数或新规模时，先用小配置（如
`--particles 200 --dim 10 --max-evals 20000`）确认命令正确并感受耗时量级，
再放大到目标规模。本文不给出耗时数字——绝对耗时因机器而异，可引用数字
只来自 [03-基准测试报告.md](03-基准测试报告.md) 协议。

## 3. 基准函数

| 名称 | 搜索范围 | 最优值 | 特点 |
|---|---|---|---|
| `sphere` | [-100, 100] | 0（原点） | 单峰，最简单，适合 first test |
| `rosenbrock` | [-100, 100] | 0（全 1） | 狭长山谷，考验沿谷前进 |
| `rastrigin` | [-5.12, 5.12] | 0 | 大量局部极小，考验全局搜索 |
| `griewank` | [-600, 600] | 0 | 多峰 + 乘积项，大范围 |
| `ackley` | [-32.768, 32.768] | 0 | 多峰 + 指数外框 |

默认函数为 `rastrigin`。五个函数都是轴对齐、未平移的经典函数，适合学习与
回归测试；性能结论的可推广性以 [03-基准测试报告.md](03-基准测试报告.md)
的限定表述为准（社区基准套件如 CEC-2013 的出处见
[07-参考文献与文档写作约定.md](07-参考文献与文档写作约定.md) [R13]）。

## 4. 常见任务

### 4.1 复现一次运行

同一条命令即可，结果行逐位一致。记录命令与输出行就是完整的复现信息
（配置全部回显在结果行里）。逐位一致在同一台机器、同一工具链下成立；
跨编译器可能出现 ULP 级浮点差异（实测记录见
[03-基准测试报告.md](03-基准测试报告.md) 的跨环境比对一节）。

### 4.2 多次运行与统计分析

换 `--seed` 逐个跑，把每个配置的结果行分别追加进两个日志文件（每行一条
结果、两侧 seed 相同），然后用 `scripts/analyze_stats.py` 做配对比较：

```bash
for s in $(seq 20240229 20240258); do
  ./build/pso_serial --function sphere --max-evals 100000 --seed $s \
    --no-early-stop >> /tmp/baseline.log
  ./build/pso_serial --function sphere --max-evals 100000 --seed $s \
    --no-early-stop --linear-inertia >> /tmp/candidate.log
done
python scripts/analyze_stats.py --metric best /tmp/baseline.log /tmp/candidate.log
```

输出为配对 Wilcoxon signed-rank 与 Mann-Whitney U 两行检验结果（`--metric`
可选 `best` 或 `time`；time 结论需遵循 [03-基准测试报告.md](03-基准测试报告.md)
协议）。判断口径：p 值之外还要看效应量与符号方向，不要只报 p。

### 4.3 画收敛曲线

单次运行的轨迹文件（`--history` 产出）是纯文本，直接查看即可（见
[01-快速开始.md](01-快速开始.md) §3，其曲线即由该文件绘出）。批量汇总与
绘图走正式采集路径：

```bash
# 分配置的收敛汇总表（含成功率与 ERT）；<采集目录> 由 run_experiments.py
# --execute 采集生成，其中 manifest.json 登记每条命令、seed 与日志/轨迹路径
python scripts/summarize_convergence.py --manifest-root <采集目录>

# 生成汇总 CSV 与曲线图（需要 matplotlib，缺失时自动跳过绘图）
python scripts/plot_results.py --manifest-root <采集目录> \
  --output /tmp/summary.csv --plot /tmp/curve.png
```

注意：`scripts/analyze_convergence.py` 是被 `summarize_convergence.py`
调用的库模块，不提供命令行入口。

### 4.4 固定预算比较两种动力学

```bash
# 第一步：单 seed 对照——只验证管线与输出格式
./build/pso_serial --max-evals 100000 --seed 20240229 --no-early-stop
./build/pso_serial --max-evals 100000 --seed 20240229 --no-early-stop --linear-inertia

# 第二步：下结论需要统计——固定其余参数，换 30 个 seed 分别收集
for s in $(seq 20240229 20240258); do
  ./build/pso_serial --max-evals 100000 --seed $s --no-early-stop >> /tmp/constriction.log
  ./build/pso_serial --max-evals 100000 --seed $s --no-early-stop --linear-inertia >> /tmp/inertia.log
done

# 第三步：配对检验（同 4.2）
python scripts/analyze_stats.py --metric best /tmp/constriction.log /tmp/inertia.log
```

两次的 `--max-evals` 相同保证预算公平；单 seed 的两行输出只说明格式，
结论以第三步的检验为准。

### 4.5 跑岛模型实验

```bash
"/c/Program Files/Microsoft MPI/Bin/mpiexec.exe" -n 4 ./build/pso_mpi_island \
  --function rastrigin --particles 2000 --dim 20 --max-evals 200000 \
  --seed 20240229 --migration-interval 10
```

本节命令用于熟悉岛模型入口，其耗时不可引用。岛模型结果随 rank 数变化
（设计使然），实验必须固定 rank 数；加速比要按
[03-基准测试报告.md](03-基准测试报告.md) 协议采集（`--pin-cpus`、≥30 seed）。
`--migration-interval` 的默认值 10 是协议缺省：迁移周期权衡岛间信息传播
速度与岛内独立性（理论背景见
[07-参考文献与文档写作约定.md](07-参考文献与文档写作约定.md) [R4]），
实证比较需按 03 协议自采数据，本文不替你选值。

### 4.6 生成正式实验计划

`scripts/run_experiments.py` 默认 dry-run（只写计划不执行）：

```bash
python scripts/run_experiments.py --help
```

正式采集协议、环境要求与已冻结的结果数字见
[03-基准测试报告.md](03-基准测试报告.md)；本文不重复性能结论。

## 5. 故障诊断

| 症状 | 原因 | 处理 |
|---|---|---|
| 构建日志说 MPI 关闭 | 未找到 MS-MPI/OpenMPI | 安装后重新 configure；无 MPI 时只能构建 serial |
| `There are not enough slots` | OpenMPI 槽位不足 | 命令前加 `--oversubscribe`（本仓库 CTest 已自动带） |
| `unknown option: --xxx` | 选项不存在或拼错 | `--help` 查看合法选项；注意没有 `--ranks`（rank 数由 `mpiexec -n` 给） |
| `invalid option value` | 值域校验失败 | 检查 `particles>0`、`dim>0`、`lower<upper`、`max-evals>=particles` |
| 没有任何进度输出 | 默认安静（`--quiet`） | 加 `--verbose` |
| 结果行 `success=0` | 预算内未达到 `--target` | 加大 `--max-evals` 或放宽 `--target`；先用 `sphere` 验证管线；用 `--history` 看收敛趋势判断「还差一点」还是「停滞」 |
| mpi-ms 结果与 serial 不同 | 不该发生 | 这是缺陷，请带命令与两行结果行到 https://github.com/Circumsized/PSO/issues 报告 |
| mpi-island 结果与 serial 不同 | 设计豁免（[02-优化设计方案.md](02-优化设计方案.md) §3.3） | 预期行为；比较时固定 rank 数 |
| 计时数字波动大 | 单次运行受调度影响 | 用 `--pin-cpus` 并遵循 docs/03 协议；单次运行不可引用 |
| 写 history 失败（退出码非零） | 路径不可写/磁盘满 | 换可写路径；求解器对写失败硬失败而非静默丢弃 |
