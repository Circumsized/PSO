## 1. 目的

本文集中记录两类信息：

1. 本项目算法和实现所引用的公开来源。
2. 本项目中文技术文档采用的结构和句法约定。

本文不把公开文献的结论直接转化为本项目的实测结论。每个工程结论必须有当前源码、测试或结果目录中的证据。

## 2. 文档写作约定

### 2.1 语言范围

本项目文档使用简体中文。

ASD-STE100 是面向英语技术文档的受控自然语言规范。本文借鉴以下写作原则：

- 一句话只表达一个主要动作或条件。
- 优先使用主动语态。
- 为同一概念使用同一个术语。
- 使用直接的命令句描述操作。
- 把前置条件写在步骤之前。
- 把失败条件写在步骤之后。
- 用表格表达参数、判定和输出。

本文不声明中文文档符合 ASD-STE100 的词汇限制、语法限制或认证要求。

### 2.2 参考页结构

本文档族借鉴 MathWorks `particleswarm` 参考页的信息组织方式：

1. 文档信息；
2. 范围或语法；
3. 说明；
4. 输入参数；
5. 输出参数；
6. 示例；
7. 算法或实现；
8. 错误和限制；
9. 参考资料；
10. 相关文档。

此处只借鉴信息架构。项目不提供 MATLAB `particleswarm` 函数，也不支持 MATLAB 参数对象。

### 2.3 术语规则

首次出现的术语使用“中文名（英文名）”形式。后文只使用中文名或已定义的字段名。

以下术语使用固定含义。英文标识只在需要对应代码或字段时保留。

| 术语或标识 | 定义与使用边界 |
|---|---|
| 评估（evaluation） | 对一个粒子位置求值一次；不等于完成一代。 |
| 评估预算 | 配置的评估上限；不等于实际评估数。 |
| 串行入口 | `pso_serial` 单进程入口；编译时启用 OpenMP 后也可使用线程。 |
| 数据并行 | 同一全局粒子集合的分块更新；结果名为 `mpi-data-parallel`。 |
| 岛模型（island model） | 本岛更新加周期迁移；不要泛称为与串行等价的 MPI 加速。 |
| pbest | 单个粒子的历史最好位置及对应适应度。 |
| social best | 当前代用于社会项的位置；按入口区分全局或本岛。 |
| 全局最好值 | 所有已访问位置中的最小适应度；不代表全局最优性证明。 |
| 结果行 | 一次正常求解产生的 `pso_v1` 记录。 |
| 轨迹文件（sidecar） | 保存初始化及每代结束时 best-so-far 的文件。 |
| rank | MPI 通信域中的进程编号，从 0 开始。 |
| FE / FEs | 函数评估 / 函数评估次数。 |

### 2.4 规范词

规范要求使用以下词语：

| 词语 | 用法 |
|---|---|
| 必须 | 违反后接口不能继续。 |
| 应 | 推荐的工程行为。 |
| 不应 | 应避免的行为。 |
| 可以 | 接口允许的行为。 |
| 不能 | 接口明确不支持的行为。 |

本文不使用“保证”描述统计结果。使用“在给定条件下可复现”或“当前测试支持”。

## 3. 算法来源

### [R1] PSO 原始论文

J. Kennedy and R. Eberhart, “Particle Swarm Optimization,” *Proceedings of ICNN'95 - International Conference on Neural Networks*, Perth, Australia, 1995, pp. 1942–1948, vol. 4. DOI: [10.1109/ICNN.1995.488968](https://doi.org/10.1109/ICNN.1995.488968).

用途：说明 PSO 的原始群体搜索思想和基本来源。

限制：该论文不定义本项目的 C 接口、MPI 数据分区、pso_v1 字段或固定预算协议。

### [R2] 收缩因子

M. Clerc and J. Kennedy, “The Particle Swarm—Explosion, Stability, and Convergence in a Multidimensional Complex Space,” *IEEE Transactions on Evolutionary Computation*, vol. 6, no. 1, pp. 58–73, 2002. DOI: [10.1109/4235.985692](https://doi.org/10.1109/4235.985692).

用途：说明收缩因子动力学的理论背景。

归属注：收缩因子（constriction factor）这一概念最早见于 M. Clerc, “The Swarm and the Queen: Towards a Deterministic and Adaptive Particle Swarm Optimization,” *Proceedings of the IEEE Congress on Evolutionary Computation*, 1999；[R2] 是其与 Kennedy 合作的后续期刊定稿，此处按完整发表版本引用。

限制：该来源不证明当前参数在每个目标函数、每个维度和有限预算下达到全局最优。当前代码的系数解释见 [05-PSO算法与优化理论.md](05-PSO算法与优化理论.md)。

### [R3] 惯性权重

Y. Shi and R. Eberhart, “A Modified Particle Swarm Optimizer,” *1998 IEEE International Conference on Evolutionary Computation Proceedings. IEEE World Congress on Computational Intelligence*, pp. 69–73, 1998. DOI: [10.1109/ICEC.1998.699146](https://doi.org/10.1109/ICEC.1998.699146).

用途：说明惯性权重作为 PSO 动力学参数的研究背景。

归属注：本项目 `--linear-inertia` 采用的"线性递减惯性权重"（w 从 0.9 衰减到 0.4）这一常用策略出自 Y. Shi and R. Eberhart, “Empirical Study of Particle Swarm Optimization,” *Proceedings of the 1999 Congress on Evolutionary Computation*, 1999；[R3] 是惯性权重概念的原始提出，此处一并记源。

限制：本项目的 `--linear-inertia` 是当前工程中的对照实现。文献中的其他参数策略不自动属于本项目接口。

### [R4] 岛模型迁移拓扑

M. Ruciński, D. Izzo, and F. Biscani. “On the impact of the migration topology on the Island Model.” *Parallel Computing*, 36(10–11): 555–571, 2010. DOI：[10.1016/j.parco.2010.04.002](https://doi.org/10.1016/j.parco.2010.04.002)。开放预印本：[arXiv:1004.4541](https://arxiv.org/abs/1004.4541)。

用途：说明迁移拓扑会影响岛模型的性能和信息传播。

限制：该来源研究的是并行差分进化和带自适应邻域的模拟退火。它不是本项目 PSO 环形迁移的直接性能证明。本项目的环形迁移结论必须以本项目的配置和实测数据为准。

### [R5] 伪随机数生成器

D. Blackman and S. Vigna, “Scrambled Linear Pseudorandom Number Generators,” *ACM Transactions on Mathematical Software*, vol. 47, no. 4, article 36, 2021, pp. 1–32. DOI: [10.1145/3460772](https://doi.org/10.1145/3460772). Generator information: [A PRNG shootout](https://prng.di.unimi.it/).

用途：说明 xoshiro256++ 的生成器背景和适用范围。

限制：作者页面明确说明该生成器不是密码学安全生成器。本项目使用它进行可复现实验采样，不使用它保护秘密。

### [R8] MPI 集合通信匹配规则

Message Passing Interface Forum, “MPI: A Message-Passing Interface Standard, Version 3.1,” 2015, [https://www.mpi-forum.org/docs/](https://www.mpi-forum.org/docs/).

### [R9] OpenMPI 启动器的绑核语义

Open MPI, "orterun, mpirun, mpiexec — Execute serial and parallel jobs in Open MPI," mpirun(1) man page, v4.1, https://www.open-mpi.org/doc/v4.1/man1/mpirun.1.php

用途：支撑 docs/03 采集条件段关于 OpenMPI 默认绑核（自 v1.8 系列起；无进一步指令时 np≤2 绑 core、np>2 绑 socket、超售时不绑核）与 `--bind-to none`、`--oversubscribe` 语义的表述。

限制：该 man page 未给出 "not enough slots" 报错原文（该表述仅有多处互相一致的第三方转录）；v5.x 起文档迁至 docs.open-mpi.org，其默认绑定行为未在本次核实范围内。文档抓取于 2026-11-20。

### [R10] MS-MPI mpiexec 的亲和性控制

Microsoft, "Environment Variables for the mpiexec Command," Microsoft Learn（HPC Pack 视图）, https://learn.microsoft.com/en-us/powershell/high-performance-computing/environment-variables-for-the-mpiexec-command

Microsoft, "Microsoft-MPI 源码: src/mpi/mpiexec/mp_parse_command_line.cpp," https://github.com/microsoft/Microsoft-MPI

用途：支撑 `MPIEXEC_AFFINITY=0` 即关闭 mpiexec 绑核（"Disabled = 0 - Does not assign affinity to any process"）、环境变量与命令行选项的优先级关系（显式选项覆盖环境变量）、未指定时默认 spread 绑核、以及 MS-MPI mpiexec 无 `--version` 开关（合法开关集见 `-help2`，版本号只在裸 `mpiexec` 帮助头部出现）的表述。

限制：Learn 页面属 HPC Pack 文档集，MS-MPI 自身的支持情况以一方源码为准；退出码 127 为本项目本机实测值，无公开文档记载。文档与源码核验于 2026-11-20。

### [R11] 无偏区间整数生成

D. Lemire, "Fast Random Integer Generation in an Interval," ACM Transactions on Modeling and Computer Simulation, vol. 29, no. 1, pp. 1–12, 2019. DOI: [10.1145/3230636](https://doi.org/10.1145/3230636)；作者手版：https://arxiv.org/abs/1805.10941

用途：说明 `pso_rng_below` 拒绝阈值 `(2^64-n)%n` 的出处与无偏性论证（Lemma 4.1：拒绝后每个输出值恰有 ⌊2^64/n⌋ 个原像）。

限制：本项目 `pso_rng_below` 采用经典无偏取模（拒绝后返回 `v%n`，arc4random_uniform 同式），不是 Lemire Algorithm 5 的乘积高位变体；该函数当前无生产调用方，仅测试使用。未检索到 2021 年后的公开修正或勘误。

### [R12] 并行随机流的种子派生

NumPy, "Parallel random number generation," NumPy 手册, https://numpy.org/doc/stable/reference/random/parallel.html

用途：SeedSequence 的熵混合与 spawn 树派生机制；对 `root_seed + worker_id` 式仿射派生的官方判词（UNSAFE：多轮运行仅增减根种子时，各 worker 种子集重叠，部分 worker 得到完全相同的流，导致总体结果偏差）。

限制：该判词针对经 SeedSequence 播种的生成器路径，Philox 等计数器型生成器有例外。本项目 `pso_rng_seed_stream` 的乘法式仿射派生对主流做法的偏离及「不修改」决策，归档于 `include/pso_rng.h` 的已知限制注。

### [R13] PSO 基准套件的社区标准

M. Zambrano-Bigiarini, M. Clerc, and R. Rojas, "Standard Particle Swarm Optimisation 2011 at CEC-2013: A baseline for future PSO improvements," Proceedings of the IEEE Congress on Evolutionary Computation, 2013, pp. 2337–2344.

J. J. Liang, B. Y. Qu, P. N. Suganthan, and A. G. Hernández-Díaz, "Problem Definitions and Evaluation Criteria for the CEC 2013 Special Session on Real-Parameter Optimization," Technical Report 201212, Zhengzhou University / Nanyang Technological University, 2013.

用途：说明 PSO 社区基准套件（CEC-2013 的 28 个平移/旋转/组合函数）与 SPSO-2011 基线的出处；SPSO-2011 在单峰与可分离函数上表现最佳、在全部组合函数上最弱，是「仅在轴对齐未平移函数上评测会高估 PSO 性能」这一论断的实证背景。

限制：本项目 5 个基准函数（sphere/rosenbrock/rastrigin/griewank/ackley）为轴对齐、未平移的经典函数，只可作回归与冒烟套件；性能结论的可推广性以 docs/03 的限定表述为准，不因引用本条而扩展。IEEE 论文原文未直读，页码与摘要经学术索引转录（单源待证）。

## 6. 维护规则

1. 修改 CLI 参数时，同时修改源代码帮助、`docs/06` 和相关测试。
2. 修改 `pso_v1` 字段时，同时修改结果输出、解析器、CTest 正则和接口文档。
3. 修改算法公式时，同时修改 `docs/05`、对应数值金标准和 CHANGELOG。
4. 修改测量环境时，区分“当前验证环境”和“历史结果环境”。不要用当前编译器版本替代历史 manifest 中的版本。
5. 新增外部来源时，记录作者、标题、年份、载体、DOI 或官方 URL，并写出该来源支持的主张和不支持的主张。
6. 不把一次运行结果写成普遍性能结论。
